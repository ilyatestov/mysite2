# Безопасность MySite2

## Обзор безопасности

MySite2 реализует современные практики безопасности для защиты данных пользователей и системы в целом.

## Аутентификация и авторизация

### JWT Токены
- Все API запросы требуют аутентификации через JWT токены
- Токены генерируются при регистрации и логине
- Время жизни токенов: 24 часа
- Токены передаются в заголовках HTTP в формате `Authorization: Bearer <token>`

### Роли пользователей
Система поддерживает следующие роли:
- **user**: Обычный пользователь
- **moderator**: Модератор с ограниченными правами
- **admin**: Администратор с полными правами

### RBAC (Role-Based Access Control)
- Все маршруты защищены middleware для проверки ролей
- Пользователи могут изменять только свои данные (кроме админов)
- Административные функции доступны только админам

## Защита от атак

### SQL Injection
- Используется Sequelize ORM с параметризованными запросами
- Все входные данные валидируются перед обработкой
- Не используются конкатенации строк в SQL запросах

### CSRF Protection
- Защита от CSRF атак реализована через заголовки и проверку токенов
- Все POST/PUT/DELETE запросы требуют валидацию

### XSS Protection
- Все входные данные экранируются при выводе
- Используются безопасные методы отображения данных

## Защита паролей

### Хэширование
- Пароли хэшируются с использованием bcrypt с солью
- Сложность хэширования: 10 rounds
- Пароли никогда не хранятся в открытом виде

## Безопасность данных

### Конфиденциальность
- Вся личная информация шифруется при хранении
- Логи не содержат чувствительных данных
- Все API ответы содержат только необходимую информацию

### Логирование
- Административные действия логируются в базе данных
- Все критические операции записываются в журнал
- Логи содержат IP адрес, время и действие

## Конфигурация безопасности

### Environment Variables
- Все секретные данные хранятся в .env файле
- Файл .env не отслеживается в Git
- Используются стандартные переменные окружения

### Middleware
- Helmet.js для защиты HTTP заголовков
- CORS настроена с ограничениями
- Morgan для логирования запросов

## Проверка безопасности

### Тестирование
- Все функции безопасности протестированы
- Используются unit и integration тесты
- Проверяется корректность RBAC
- Тестируется защита от SQL injection и XSS

### Регулярные проверки
- Регулярная проверка на уязвимости
- Обновление зависимостей
- Повторное тестирование безопасности при изменениях
