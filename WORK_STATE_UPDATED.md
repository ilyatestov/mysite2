# Состояние работы над MySite2

## Общая информация

Проект MySite2 - это полнофункциональный веб-сайт с блогом, системой сообщений, реферальной программой, административной панелью, магазином и другими функциями.

## Выполненные задачи

### 1. Реализация RBAC системы (Role-Based Access Control)

#### Созданы middleware:
- **authorize** - проверяет, что пользователь имеет нужную роль
- **isOwner** - проверяет, что пользователь является владельцем ресурса
- **checkPermission** - базовая структура для проверки конкретных прав доступа
- **validateRoleChange** - защита от массового присвоения полей при изменении ролей

#### Обновлены все маршруты с применением RBAC:
- **Пользователи (users.js)** - GET/PUT/DELETE с защитой по ролям и принадлежности
- **Посты (posts.js)** - POST/PUT/DELETE с защитой по ролям и принадлежности
- **Категории (categories.js)** - POST/PUT/DELETE с защитой по ролям
- **Теги (tags.js)** - POST/PUT/DELETE с защитой по ролям
- **Комментарии (comments.js)** - GET/POST/PUT/DELETE с защитой по ролям и принадлежности
- **Сообщения (messages.js)** - GET/POST/PUT/DELETE с защитой по ролям и принадлежности
- **Рефералы (referrals.js)** - GET/POST/PUT/DELETE с защитой по ролям и принадлежности
