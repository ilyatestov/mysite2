# Реферальная программа

## Обзор реферальной программы

Реферальная программа позволяет приглашать друзей на сайт и получать бонусы за это.

## Как начать

Для начала работы с реферальной программой:

1. Перейдите в раздел "Рефералы" в вашем профиле
2. Скопируйте ваш реферальный код
3. Поделитесь кодом с друзьями

## Ваш реферальный код

Каждый пользователь получает уникальный реферальный код:

- Код состоит из букв и цифр
- Код можно использовать для приглашения друзей
- Код действует бессрочно
- Код можно скопировать в любое время

## Приглашение друзей

Чтобы пригласить друга:

1. Отправьте ваш реферальный код другу
2. Друг должен зарегистрироваться по вашей ссылке
3. После регистрации друг становится вашим рефералом

## Бонусы и награды

За приглашенных друзей вы получаете:

- Денежные бонусы (в зависимости от программы)
- Бонусные баллы
- Доступ к эксклюзивным функциям
- Повышение статуса

## Статистика рефералов

В статистике вы можете отслеживать:

- Количество приглашенных друзей
- Статус рефералов (активные/неактивные)
- Полученные бонусы
- Дату регистрации рефералов
- Статистика по активности

## Правила программы

- Один реферальный код может быть использован только один раз
- Рефералы должны быть зарегистрированы через ваш код
- Бонусы начисляются после подтверждения регистрации реферала
- Программа может быть изменена администратором

Если у вас возникли вопросы по реферальной программе:

1. Обратитесь в службу поддержки
2. Проверьте FAQ раздел
3. Ознакомьтесь с правилами программы
