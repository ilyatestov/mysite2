# Система сообщений

## Обзор системы сообщений

Система сообщений позволяет обмениваться личными сообщениями с другими пользователями сайта.

## Доступ к сообщениям

Для доступа к системе сообщений:

1. Нажмите на иконку сообщений в верхнем меню
2. Или перейдите в раздел "Сообщения" в профиле

## Отправка сообщения

Для отправки сообщения:

1. Нажмите кнопку "Новое сообщение"
2. Выберите получателя из списка пользователей
3. Напишите текст сообщения
4. Нажмите "Отправить"

### Требования к сообщению:

- Текст сообщения: минимум 1 символ
- Получатель: должен быть зарегистрированным пользователем

## Просмотр сообщений

В системе сообщений вы можете:

- Просматривать входящие сообщения
- Просматривать исходящие сообщения
- Просматривать архив сообщений
- Удалять сообщения

## Управление диалогами

Вы можете управлять диалогами:

- Удалять диалоги
- Ставить диалоги в избранное
- Фильтровать диалоги
- Сортировать по дате или имени

## Уведомления

Система уведомляет вас о:

- Новых сообщениях
- Ответах на ваши сообщения
- Статусе доставки сообщений

## Настройки уведомлений

Вы можете настроить уведомления:

- Включить/отключить уведомления
- Настроить частоту уведомлений
- Выбрать типы уведомлений
- Настроить звуковые уведомления

## Безопасность

Система обеспечивает безопасность:

- Шифрование сообщений
- Конфиденциальность диалогов
- Возможность блокировки пользователей
- Отслеживание активности
