# Принятые решения

## 1. Технологический стек

### Backend
- Используем Node.js с Express.js как основной фреймворк
- Для базы данных выберем SQLite для development среды
- Для production будем использовать PostgreSQL (согласно ТЗ)

### Frontend
- Начнем с HTML/CSS/JavaScript для базовой реализации
- Возможная интеграция React.js для более сложных компонентов
- Используем EJS шаблонизатор для серверных рендерингов

### Аутентификация
- JWT токены для аутентификации
- Поддержка ролей пользователей (admin, user, moderator)

### Тестирование
- Jest для unit тестов
- Supertest для интеграционных тестов
- Puppeteer для E2E тестов

## 2. Архитектура проекта

### Структура папок
```
mysite2/
├── src/
│   ├── controllers/
│   ├── models/
│   ├── routes/
│   ├── middleware/
│   ├── views/ (для EJS)
│   ├── public/ (статические файлы)
│   ├── config/ (конфигурации)
│   └── utils/
├── tests/
├── data/ (seed данные)
├── migrations/ (миграции БД)
├── docs/
└── package.json
```

### База данных
- Для development: SQLite
- Для production: PostgreSQL
- ORM: Sequelize или Prisma (выберем после анализа требований)

## 3. Реализация модулей

### Блог
- Посты с категориями и тегами
- Комментарии к постам
- Модерация комментариев

### Сообщения
- Личные сообщения между пользователями
- Диалоги
- Уведомления о новых сообщениях

### Реферальная система
- Система рефералов с бонусами
- Отслеживание рефералов
- Логирование реферальных ссылок

### Админка
- Полный CRUD для всех сущностей
- Журнал действий
- Настройки сайта

### Магазин
- Каталог товаров
- Корзина
- Тестовые заказы
- Система управления товарами

## 4. Тестирование

- Unit тесты для всех моделей и контроллеров
- Integration тесты для API
- E2E тесты для ключевых сценариев
- Покрытие кода тестами не менее 80%
