# Реализация RBAC системы для MySite2

## Обзор

RBAC (Role-Based Access Control) система обеспечивает безопасный доступ к ресурсам приложения на основе ролей пользователей. В проекте MySite2 реализована полная система ролей с защитой маршрутов и данных.

## Роли пользователей

### 1. user (обычный пользователь)
- Может создавать и редактировать свои посты
- Может создавать комментарии
- Может отправлять личные сообщения
- Может использовать реферальную программу
- Может просматривать публичные данные

### 2. moderator (модератор)
- Все права обычного пользователя
- Может управлять категориями и тегами
- Может редактировать и удалять чужие посты (в рамках модерации)
- Может управлять комментариями

### 3. admin (администратор)
- Все права модератора
- Может управлять пользователями
- Может управлять всеми ресурсами системы
- Может просматривать и управлять административными логами

## Middleware RBAC

### authorize
Middleware для проверки ролей пользователя

**Использование:**
```javascript
// Разрешить только администраторам
router.get('/admin-only', authorize(['admin']), handler);

// Разрешить пользователям и модераторам
router.get('/moderator-only', authorize(['user', 'moderator']), handler);

// Разрешить всем авторизованным пользователям
router.get('/authenticated', authorize(), handler);
```

**Параметры:**
- `roles` (Array): Массив разрешенных ролей

### isOwner
Middleware для проверки принадлежности ресурса пользователю

**Использование:**
```javascript
// Проверка принадлежности ресурса
router.put('/:id', isOwner(), handler);
```

**Особенности:**
- Администраторы имеют полный доступ
- Для других ролей проверяет принадлежность ресурса
- В реальной реализации будет проверяться в БД

### checkPermission
Middleware для проверки конкретных прав доступа

**Использование:**
```javascript
// Проверка конкретного права доступа
router.get('/special-feature', checkPermission('special_access'), handler);
```

### validateRoleChange
Middleware для валидации изменений ролей

**Использование:**
```javascript
// Только администраторы могут изменять роли пользователей
router.put('/:id', validateRoleChange, handler);
```

## Защита маршрутов

### Маршруты пользователей (users.js)
- GET /users - только администраторы
- GET /users/:id - владелец или администратор
- PUT /users/:id - владелец или администратор + валидация ролей
- DELETE /users/:id - владелец или администратор

### Маршруты постов (posts.js)
- POST /posts - авторизованные пользователи
- PUT /posts/:id - владелец или администратор
- DELETE /posts/:id - владелец или администратор

### Маршруты категорий (categories.js)
- POST /categories - модераторы и администраторы
- PUT /categories/:id - модераторы и администраторы
- DELETE /categories/:id - модераторы и администраторы

### Маршруты тегов (tags.js)
- POST /tags - модераторы и администраторы
- PUT /tags/:id - модераторы и администраторы
- DELETE /tags/:id - модераторы и администраторы

### Маршруты комментариев (comments.js)
- GET /comments - только администраторы
- GET /comments/:id - владелец или администратор
- POST /comments - авторизованные пользователи
- PUT /comments/:id - владелец или администратор
- DELETE /comments/:id - владелец или администратор

### Маршруты сообщений (messages.js)
- GET /messages - только администраторы
- GET /messages/:id - владелец или администратор
- POST /messages - авторизованные пользователи
- PUT /messages/:id - владелец или администратор
- DELETE /messages/:id - владелец или администратор
- GET /messages/user/:userId - владелец или администратор
- PUT /messages/:id/read - владелец

### Маршруты рефералов (referrals.js)
- GET /referrals - только администраторы
- GET /referrals/:id - владелец или администратор
- POST /referrals - авторизованные пользователи
- PUT /referrals/:id - владелец или администратор
- DELETE /referrals/:id - владелец или администратор
- GET /referrals/user/:userId - владелец или администратор
- PUT /referrals/:id/activate - владелец или администратор
